# Contribuire ad Arabica

Grazie per voler contribuire. Per modifiche sostanziali, apri prima una Issue spiegando il cambiamento proposto.

## Sviluppo

```bash
npm install
npm run dev
```

Prima di una Pull Request:

```bash
npm run typecheck
npm run build
```

## Contenuti linguistici

Le correzioni di arabo sono particolarmente importanti. Quando aggiungi lezioni o vocaboli:
- usa arabo standard moderno (MSA) salvo indicazione esplicita del dialetto;
- aggiungi traslitterazione e traduzione italiana;
- evita traduzioni letterali fuorvianti;
- segnala nelle note quando una forma cambia per genere o registro.
